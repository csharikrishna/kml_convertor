Have a .DWG file?

This tool requires .DXF files (the open standard for CAD data).
To convert your DWG:
1. Open your DWG file in AutoCAD (or any free CAD viewer).
2. Go to File > Save As...
3. Select AutoCAD DXF (*.dxf) from the file type dropdown.
4. Save and upload the resulting DXF file here!
